for anio, real in reales:
    if real > mejor_real:
        mejor_anio, mejor_real = anio, real
    if real < peor_real:
        peor_anio, peor_real = anio, real

print("Mejor año:", mejor_anio, mejor_real, "%")
print("Peor año:", peor_anio, peor_real, "%")
        
      
        «El mejor hasta ahora» es la idea detrás de max(). Empezar con el primer registro, y no con 0, hace que el programa funcione aunque todos los valores sean negativos. Entre 2021 y 2025 el salario mínimo pasó de perder 2,70 % de poder de compra a ganar 6,53 %.

        Notas y método
        
  
        ¿Cómo corre Python dentro de esta página?
        Con Pyodide, una versión de Python que funciona dentro del navegador. La primera vez se descargan unos 10 MB; después queda guardado. Su código no se envía a ningún servidor: corre en su equipo, y lo que escribe se guarda solo en este navegador. Una alarma detiene cualquier programa que dé más de 200.000 pasos, para que un ciclo infinito no congele la página.
        
  
        ¿Cómo se califica cada ejercicio?
        El taller ejecuta su programa y revisa el valor final de las variables que pide el ejercicio; el recuadro muestra cada comprobación con ✓ o ✗. Después lo corre otra vez con un dato cambiado: si usted escribió un resultado a mano en vez de calcularlo, ahí se nota. También revisa que use lo que el ejercicio pide (una posición negativa, una tajada, .append(), desempacar, un for). Los errores de Python se traducen al español, con el número de línea y una pista. Nada de esto es una nota: es práctica.
        
  
        ¿De dónde salen los datos?
        Son reales: la inflación anual de 2015 a 2025 (DANE, IPC, variación de diciembre a diciembre) y el salario mínimo de 2021 a 2026 con sus aumentos (decretos anuales). La variación real se calcula a partir de ellos. La inflación de 4,5 % para 2026 es un supuesto, porque esa cifra todavía no se conoce.
        
  
        ¿Por qué el código escribe anio y no año?
        Python acepta la ñ en los nombres de las variables, pero no todos los teclados ni todas las herramientas la manejan bien. Por eso la guía y el taller escriben anio.
